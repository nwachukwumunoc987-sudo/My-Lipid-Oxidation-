# My-Lipid-Oxidation-
Because most times hard copy documentation can get missing, torn or damped. Not just that, due to infrastructural defects, Peroxide values and SAP values tend to shoot up sporadically and predicting it because hard. We will use this repository to predict and model the outcome from other from other known and easy to analyse paremeter values.
# This will go ahead to do the following
Compares Peroxide Value (PV) of Crude Palm Kernel Oil (CPKO) vs Refined Vegetable Oil (RVO) over storage time.

## Folders
- `script/` - Python code
- `data/` - CSV data
- `plot/` - Plot

## Models
- PV vs Days (for both oils)
- PV vs FFA + Moisture Content (for both oils)
